# WindowKeeper（ウインドウキーパー）

モニターのつなぎ方ごとにウインドウの配置を覚えておき、つなぎ直したときに元の場所へ戻す、macOS のメニューバー常駐アプリです。

職場の外部モニター、自宅のモニター、MacBook 単体。それぞれで「いつもの並び」を一度保存しておけば、ケーブルをつなぐだけで元に戻ります。

## できること

- **構成ごとに配置を保存**：つながっているモニターの組み合わせを見分け、その構成の配置として保存します。
- **つないだら自動で戻す**：モニターの接続を検知して、保存した配置に戻します。メニューから手動で戻すこともできます。
- **デスクトップ（Mission Control の操作スペース）も戻す**：ウインドウがどのデスクトップにあったかも覚えています。
- **モニターを外す準備**：外す前に空のデスクトップを表示して、ウインドウが 1 か所に寄せ集められるのを防ぎます。
- **配置セット**：同じ構成に複数の配置を持たせ、切り替えられます。
- **ショートカット**：よく使う操作に好きなキーを割り当てられます。

## 動作環境

- macOS 14（Sonoma）以降が対象です。動作を確認しているのは macOS 26 で、macOS 14・15 では未確認です。
- Apple シリコンの Mac で動作を確認しています。Intel の Mac 向けにも作ってありますが、実機では未確認です。

未確認の環境でうまく動かないときは、[Issues](https://github.com/DrHac-GH/windowkeeper-releases/issues) でお知らせください。7 日間のお試しで、購入前に確かめられます。

## インストール

1. [Releases](https://github.com/DrHac-GH/windowkeeper-releases/releases/latest) から `WindowKeeper-x.y.z.dmg` をダウンロードします。
2. 開いて、`WindowKeeper` を「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」から WindowKeeper を起動します。メニューバーにウインドウの形のアイコンが出ます。

Apple の公証を受けているので、初回起動時の警告は「開く」を押すだけです。

## 最初の設定（アクセシビリティの許可）

ほかのアプリのウインドウを動かすために、macOS の許可が必要です。

1. メニューバーのアイコンから「アクセシビリティを許可…」を選びます。
2. 「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」が開きます。
3. 一覧の WindowKeeper をオンにします。

許可するまで、アイコンは警告の三角形で表示されます。

## 使い方

| やりたいこと | 操作 |
| --- | --- |
| 今の並びを保存する | メニューの「今の配置を保存」、または ⌃⌥⌘S |
| 保存した並びに戻す | メニューの「この構成の配置に戻す」 |
| モニターを外す前の準備 | メニューの「モニターを外す準備」、または ⌃⌥⌘E |
| 配置セットを切り替える | メニューの「配置セット」、または ⌃⌥⌘1〜9 |
| 保存した内容を見る | メニューの「保存一覧を開く…」 |

「今の配置を保存」と「モニターを外す準備」のキーは、「設定…」→「ショートカット」で変えられます。

自動で戻したくないときは、メニューの「ディスプレイ接続時に自動で戻す」をオフにします。

## お試しと解除コード

- 最初の 7 日間は、すべての機能を使えます。残りの日数はメニューに表示されます。
- 8 日目以降は、解除コードを入れるまで保存と復元が止まります。**保存済みの配置は消えません。** コードを入れると、そのまま使えます。
- 解除コードは、販売している記事に記載しています。メニューの「解除コードを入力…」から入力します。
- 1 つのコードで、ご自身の Mac 3 台まで使えます。

## アップデート

新しい版が出ると、起動中に案内が出ます。メニューの「アップデートを確認…」から手動でも確認できます。

## プライバシー

ウインドウの情報（アプリ名、タイトル、位置）は、この Mac の中にだけ保存し、外部へ送りません。詳しくは [プライバシーについて](docs/PRIVACY.md) をご覧ください。

## 知っておいてほしいこと

- デスクトップ（操作スペース）の移動には、macOS が公開していない仕組みを使っています。macOS の更新で、この部分が一時的に動かなくなることがあります。そのときはアップデートで対応します。
- フルスクリーンのウインドウ、位置を変えられないウインドウなど、アプリの作りによって戻せないものがあります。戻せなかったものはメニューに一覧で出ます。
- ウインドウは「アプリ名とタイトル」で見分けています。同じタイトルのウインドウが複数あると、入れ替わることがあります。

## アンインストール

1. メニューから「WindowKeeper を終了」を選びます。
2. 「アプリケーション」の WindowKeeper をゴミ箱に入れます。
3. 保存した配置も消す場合は、`~/Library/Application Support/WindowKeeper/` を削除します。
