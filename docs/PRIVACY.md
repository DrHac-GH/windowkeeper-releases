# プライバシーについて

最終更新: 2026 年 11 月 20 日

WindowKeeper は、利用者の情報を集めないアプリです。ウインドウの情報は、この Mac の外へ出しません。

## アプリが扱う情報

配置を保存して戻すために、次の情報を読み取ります。

- 開いているウインドウのアプリ名、タイトル、位置、大きさ
- ウインドウがあるデスクトップ（操作スペース）
- つながっているモニターの種類と並び方

ウインドウの中身（文章、画像、入力した内容）は読み取りません。

## 保存する場所

読み取った情報は、この Mac の中にだけ保存します。

| 内容 | 場所 |
| --- | --- |
| 保存した配置 | `~/Library/Application Support/WindowKeeper/layouts/` |
| 動作の記録（不具合を調べるためのログ） | `~/Library/Application Support/WindowKeeper/log.txt` |
| 設定、お試しの開始日、解除の状態 | macOS の設定領域（UserDefaults） |

これらを外部のサーバーへ送る機能はありません。iCloud などへの同期もしません。

## 外部との通信

通信するのは、アップデートの確認だけです。

- 新しい版があるかを調べるため、GitHub（`github.com`）に置いた更新情報のファイルを取りに行きます。
- このとき相手に伝わるのは、通常のウェブ閲覧と同じ範囲（IP アドレス、アプリの版番号など）です。ウインドウの情報、Mac の構成、利用状況は送りません。
- 更新をダウンロードするときも、同じく GitHub と通信します。

広告、アクセス解析、利用状況の収集は入れていません。

## 解除コード

入力した解除コードは、この Mac の中で照合します。コードや購入者の情報をサーバーへ送ることはありません。

## アクセシビリティの許可

ほかのアプリのウインドウを動かすために、macOS の「アクセシビリティ」の許可を使います。この許可は、ウインドウの位置と大きさの読み取りと変更、デスクトップの切り替えにだけ使います。

## 情報を消すには

`~/Library/Application Support/WindowKeeper/` を削除すると、保存した配置とログが消えます。
